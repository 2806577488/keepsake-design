## A. 全局（不过就退回）

- [ ] 全项目 grep `0xFF`，除 `skin_tokens.dart` 外为 0 处。

## B. 颜色

- [ ] `primaryContainer` 与 `surfaceContainerLow` 的明度差 ≥ 8%（用取色器量）。
- [ ] 错误条：底色是 `#FFDAD6`，文字深红，**不是** `#BA1A1A` 铺满。
- [ ] 停止生成按钮同样用 `errorContainer`，不是 `error`。
- [ ] E 皮肤的主色块是陶土橙（`#FFDCC8` / `#D9622B`），不是薄荷绿。
- [ ] H 皮肤的 AI 气泡是深青底（`#1F4A42`）+ 浅青字（`#A7E6D5`）。
- [ ] FAB 是三套都 1px `#8CCDBB` 描边 + `surface` 底，**没有阴影**。

## C. E 皮肤专项（最容易只换颜色不换形态）

- [ ] 元信息（时间、轮数、token 数）**是等宽的**。捞一行看，数字和中文都是等宽。
- [ ] 卡片有了 1px 描边，颜色是 `#E3EAE6`（浅），**不是** `#CAD1CD`（会太抢眼）。
- [ ] 圆角是 8 / 6 / 4 这一档，不是 A 的 16 / 14。
- [ ] chip 是方角（4），不是胶囊。
- [ ] 图标是描边的（`_outlined`），不是实心。
- [ ] `more_vert` / `stop` / `graphic_eq` / `language` / `cloud_download` / `settings` / `verified` / `push_pin` / `select_all` / `tune` 这 10 个**保持实心**（描边会糊）。

## 23. 改完必须跑一致性校验

改完 token 之后，跑一次：

```
python check_consistency.py --ref reference/full-list.html --dart skin_tokens.dart --spec SPEC.md
```

它会对比**设计稿 HTML** 和 **skin_tokens.dart** 的每一项数值，不一致就以非 0 退出。

> 为什么有这条：v3 第一次交付时，`skin_tokens.dart` 里 E 的 `fsTitle` 还是 16，
> 但改动说明写的是 15——因为改了 HTML 没重新生成 dart。
> 这种「改了源头忘了同步下游」的错，肉眼几乎发现不了，所以做成脚本。

## 24. 交互态（v3.1）：按压不许出灰块

- [ ] 点「联网 / 思考 / 上下文」chip：只有 **32dp 本体**底色变（`high`），
      **不许**出现比本体大一圈的灰色矩形 / 水波纹（那是 Material 默认 Ink 画在 48dp 触摸框上）。
- [ ] 开态 chip 按下**不加深**（保持 `primary-container`），避免"整块闪一下"。
- [ ] 按压时文字不位移：不改 padding / 字号 / 行高，只换底色。
- [ ] 参考稿在手机浏览器里点 chip 没有灰色点按高亮（`-webkit-tap-highlight-color: transparent` 生效）。
- [ ] 工程侧对应实现：`InkWell(splashFactory: NoSplash.splashFactory, highlightColor: transparent, onHighlightChanged: …)`，
      背景按 `_pressed` 切 `transparent` / `high`。

## 25. 轻提示（v3.2）：不许贴在底部输入区

- [ ] 任何提示（toast）都出现在**顶部**（状态栏 + 56 + 8），不在底部、不压输入栏。
- [ ] 提示出现 / 消失时页面**不位移**（浮层，不是插进布局的条）。
- [ ] 提示不拦手势：出现时还能继续打字、滚动、点按钮。
- [ ] 同屏只有一条：连续点两次，新的顶掉旧的，不叠成一摞。
- [ ] 2 秒自动消失；出现动画 120ms（淡入 + 8dp 上浮）。
- [ ] 工程侧对应实现：`lib/core/ui/toast.dart` 的 `showTopToast()`，**不要**再用
      `ScaffoldMessenger.showSnackBar`（默认就贴底部）。

## 26. 信息架构（v3.3）：全局操作不进单条菜单

- [ ] 聊天页顶栏 ⋮ **只有「设置」一项**，不许往里塞会话操作。

## 27. 流式跟随（v3.6）：只在贴底时跟，按钮不许压字

- [ ] 流式输出时，视口停在**最新一行**，不往回跳（不许回到"输入框下方/气泡顶部"）。
- [ ] 用户上滑后**不再自动跟随**，能停在中间读；滑回底部或点按钮才恢复跟随。
- [ ] 「回到底部」按钮在**列表与工具芯片之间**（右对齐），不覆盖任何消息文字。
- [ ] 流式中的助手气泡**宽度锁定**，不随字数从窄变宽。
- [ ] 工程侧对应实现：普通 `ListView` + `ScrollController`，贴底用
      `jumpTo(position.maxScrollExtent)`；**不要**再用 `ScrollablePositionedList` 的
      `jumpTo(index, alignment: 1)`（懒加载估值在长气泡上贴不住底）。
