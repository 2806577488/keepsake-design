# 角色卡表单规范（v3.10 · 随 0.4.33 上线）

> 工程侧实现：`keepsake-app` 的 `lib/features/settings/characters_screen.dart`
> （`_CharacterCardDialog`）与 `lib/core/characters/character_service.dart`。
> 落地记录：源码库 `docs/character-card-2026-11-26.md`。

## 0. 先说清楚「角色卡」现在是什么

**App 里的角色卡 = 记忆隔离边界**（记忆 / 情绪 / 人格挂在卡上，跨卡不召回），
外加一个**只存不用**的人设备注。它**不是** DSH 插件 `dsh-brain` 里那个"由对话塑造的
角色"——后者由模型 bootstrap 并按新证据修订（见 `dsh-brain` README v2.2.0）。

所以这一版只做「止血 + 表单规范」，不假装 App 已经有人格层。

## 1. 表单结构（自上而下）

| 字段 | 控件 | 规格 |
|---|---|---|
| 名字 | 单行输入 | 必填；`maxLength 24`；空值时「保存」不可点 |
| 头像 emoji | 单行输入，**宽度 140** | `maxLength 4`；默认 🤖 |
| 简介 | 多行输入 | `minLines = maxLines = 3`；`maxLength 120` |
| 人设备注（可选） | 多行输入 | `minLines 4 / maxLines 6`；`maxLength 2000`；**下面必须跟一行说明** |

字段外观（三套皮肤统一规则，圆角取 `rCard` 而不是 `rField`）：

- 底 `highest`、1px `ov` 描边、聚焦 1.2px `selBar`；
- 圆角 **`rCard`**（A 14 / E 6 / H 12）——**不是** `rField`（A 是 999 胶囊）。
  999 套到多行输入框上会让 label 浮到框外、简介变成一块空心药丸；
- 小标题放在框**外**（`fs-sub` / `onV`），框内只放 hint；
- `isDense: true` + `contentPadding 14/12`；
- 弹窗内容区 `maxWidth 420`、`maxHeight = 屏高 × 0.6`，内部滚动。

## 2. 文案

| 位置 | 文案 |
|---|---|
| 人设备注下方 | 「会追加在「设置 › AI 平台」的全局 system prompt 之后；留空则不注入。」（v3.11 起：人设**真的**注入） |
| 名字下方（名字像会话标题时） | 「这个名字像是从会话标题来的，建议改成人物名。」 |
| 标题 | 新建：`新建角色卡`；编辑：`编辑角色卡` |
| 按钮 | `取消`（Text） / `保存`（Filled，名字为空时禁用） |

**禁止**写成「留空自动生成」：自动生成已经停用（见 §3），再这么写就是骗人。

## 3. 自动建卡与命名规则（0.4.33）

- **普通对话不再一会话一卡**：没显式名字时复用同一张默认记忆域（`source = default`
  且无人设文本），名字固定「未命名角色」，不写人设文本；
- **生成名（导入/标题）严格**：去引号与句末标点 → 长度 ≤ 12 → 不是问句/陈述句 →
  不是占位词；否则退话题词，最后退「未命名角色」；
- **手工名宽松**：只 trim，最长 24 字（超长截断加 `…`）；
- **展示不偷改**：列表显示库里存的名字（空则占位名）。历史长句卡要改名，
  由用户决定，不做静默迁移。

## 3.1 人设真的注入了（v3.11 / 0.4.34）

- 非空人设 → 以 `【角色设定】` 段**追加在全局 system prompt 之后**（稳定内容，不破坏缓存）；
  超过 1200 字截断；
- 老 bug 自动生成的垃圾人设（`你是「<名字>」…` 且名字本身不是人名）在下次对话时**惰性清空**；
  名字正常、模板未改的卡保留——那段模板是合理的默认人设；
- 所以文案从「只保存、不生效」改成「会追加在全局 prompt 之后」。

## 4. 验收

- [ ] 四类字段的高度有节奏（单行 ≈48 / 简介 3 行 / 人设 4–6 行），不是四块一样大的灰块。
- [ ] 小标题在框外，不与边框重叠、不掉进框里。
- [ ] 多行字段圆角是 `rCard`，不是胶囊。
- [ ] 名字为空时「保存」不可点。
- [ ] 名字像会话标题时出现提示，**但不自动改名**。
- [ ] 人设备注下方有"不生效"说明。
- [ ] 弹窗内容超出屏高 60% 时内部滚动，不撑破屏幕。
