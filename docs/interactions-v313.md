# v3.13 交互修复（左滑删除 / 附件 / 输入框 / 选择菜单）

本版不新增页面，全部是**既有页面的交互修复与可用性补齐**。对应工程版本：keepsake 0.4.42–0.4.43。

## 1. 会话列表：左滑删除

**旧实现（问题）**：用 `Dismissible`，红色背景只是画出来的——手指一松就弹回，那个垃圾桶图标**永远点不到**。用户只能靠对话框确认或彻底划走，视觉暗示和实际行为不一致。

**新实现（`SwipeRevealDelete`）**：

| 行为 | 规格 |
|---|---|
| 左滑 | 跟手 0..88dp；松手后**吸附**到开（-88）或关（0），不弹回 |
| 删除区 | 88dp 宽，`errorContainer` 底，右侧居中一个垃圾图标按钮（`onErrorContainer`），**真按钮** |
| 点垃圾桶 | 弹「删除会话」确认 → 确认后级联删除 |
| 滑开状态点行体 | 只收起，不进入会话 |
| 快速一甩（velocity < -700） | 直接弹确认（少一步） |
| 多选态 | 禁用左滑 |
| 上下滚动 | 水平手势独立，不影响列表滚动 |

## 2. 输入框（聊天页）

- 多行草稿时**高度/边框随内容**：`isDense: true`，去掉 `minHeight` 约束；圆角固定 16（不再跟主题 `OutlineInputBorder` 联动导致多行裁字）。
- 聚焦边框 1.5px `onSurface`；底色 `highlightest`。

## 3. 长按选择菜单

- 用 App 自绘菜单替换系统菜单：**复制 / 分享 / 全选**，中文标签。
- 不再出现第三方 App 注册的「文本处理」项（问AI / 去七猫看看 等）。
- 「分享」直接把选中文字交给系统分享面板。

## 4. 待发送附件（左下角缩略图条）

- **点图片缩略图** → 全屏预览：黑底、双指缩放（0.8–6 倍）。
- 预览左上「关闭」、右上「删除」（删除 = 从待发送列表移除并关闭预览）。
- 文件卡片（PDF/Word 等）暂不弹预览，只保留删除。
- **预上传**：附件加入待发送区即**后台上传**；点发送时只等剩余部分（通常已就绪，不转圈）。
  - 上传中缩略图显示转圈；完成转就绪态；
  - 失败标 failed，发送时重试一次；
  - 平台没配 API Key → 明确提示，不伪装成网络错误；
  - 上传中删除附件 → 结果写回前会校验，不会塞回已删项。

## 5. 设置页新增/改动

| 位置 | 项 | 行为 |
|---|---|---|
| 数据 | 导出诊断日志 | 版本/系统/脱敏设置/会话数/库大小；**不含聊天原文与 Key**；走系统分享 |
| 对话默认 | 实体字段抽取 | 每 N 轮（默认 3），**0 = 关闭**（不调用模型） |
| AI 平台编辑弹层 | Key 获取指引 | 「还没有 Key？去 DeepSeek 开放平台获取」→ 系统浏览器打开 |
| AI 平台编辑弹层 | 诊断补全 | 诊断日志会写：平台预设/名称、接口地址、Key 是否已配置 |

## 6. 「用其他应用打开」

- Manifest 声明 `ACTION_VIEW` + `text/plain` / `text/markdown`：文本文件在「用其他应用打开」里出现 Keepsake。
- 打开后读取内容（≤2MB）→ 复制到剪贴板 + Toast 提示粘贴（MVP，暂不自动建会话）。
- Word/PDF 等非文本 MIME 暂不出现（需要解析器，另开版本）。

## 验收（对应 CHECKLIST §33）

1. 左滑停住，点垃圾桶弹确认；取消后行保持滑开（不自动收起）→ 应改为收起；点行体收起。
2. 多行输入不裁字、边框随高度。
3. 长按文字，菜单只有复制/分享/全选，且是中文。
4. 点待发送图片缩略图能全屏预览，关闭/删除都可用。
5. 加图后不等发送就开始传（缩略图转圈），发送时无明显等待。
6. 设置 → 导出诊断日志，文件里不含聊天原文与 Key。
7. 把「实体字段抽取」改 0，再聊几轮，不应再有该模型调用。
8. 用文件管理器「用其他应用打开」一个 .txt，Keepsake 出现在列表里，打开后剪贴板有内容。
