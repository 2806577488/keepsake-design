# Keepsake · 设计 v3 改动说明（相对 v2）

> 基线：**v2**（工程师已落地的那个包）
> 本文档只说明 **v2 → v3 改了什么**。颜色和形态 token 大部分没动。
>
> ⚠️ **建议时机**：等当前构建/发布分离改造收尾、0.4.21 出完再落这一版。
> UI 不急着上，别打断构建线。

---

## 0. 一句话

v2 的列表是"6 条平铺，没有结构"。v3 给列表加了**时间分组、右侧时间、未读点、当前行强标**，并把多选态、长按菜单同步改造。
**E 套的标题字号从 16 降到 15**，因为宋体在 16px 下比其他两套更容易截断。

---

## 1. 列表页（最核心的改动）

### 1.1 新增：时间分组

```
今天      ← 分组标题，11px / 700 / onSurfaceVariant / 字距 0.08em
  ...
昨天
  ...
本周
  ...
本月
  ...
```

- 分组标题规格：`font-size 11` / `font-weight 700` / `color onSurfaceVariant` / `letter-spacing 0.08em`
- 上下留白：`padding 16px 16px 4px`
- **分组规则**：今天 / 昨天 / 本周（7 天内）/ 本月 / 更早

### 1.2 新增：时间移到第二行右侧

**v2**：时间藏在副标题里（"5 天前 · 10 个对话"）
**v3**：副标题只留对话数，时间移到**第二行最右**，和"10 个对话"同一行

```
帮我写一个 Python 脚本，批量重命名      ← 标题独占整行
10 个对话                     14:32      ← 元信息左 + 时间右
```

- 时间规格：`font-size 11` / `color onSurfaceVariant` / `font-variant-numeric tabular-nums` / 距左边元信息 8px
- **为什么不做成"时间在标题右侧"**：试过，标题会被挤到截断。放第二行后标题能完整显示。

### 1.3 新增：未读点

标题文字后面跟一个 **6×6 圆点**，颜色 = `selectionStroke`。

### 1.4 新增：当前对话强标

- 整行底色 = `selectionBg`
- 左侧 **3px 竖条** = `selectionStroke`
- 标题字重 700
- 头像底色 = `primaryContainer`，图标色 = `onPrimaryContainer`

### 1.5 列表行规格（变化的部分）

| 项 | v2 | v3 |
|---|---|---|
| 行高 `row-h` | 68 | 68（不变） |
| 标题 | 单行省略 | 单行省略（不变） |
| 元信息 | "时间 · N 个对话" | **只有"N 个对话"** |
| 时间 | 在元信息里 | **第二行右侧，11px** |
| 分组标题 | 无 | **11px / 700** |

---

## 2. 多选态（两屏）

### 2.1 结构变化

**v2**：复选框直接顶替头像位置
**v3**：**复选框放在 34×34 槽位里**（框本身 20×20），保持占位一致——这是 v2 自己定的红线，v3 继续遵守。

### 2.2 规格

- 槽位：`34×34`，居中放框
- 框：`20×20`，圆角 `r-cb`，边框 `2px outline`
- 选中框：底色 + 边框 = `selectionStroke`，白色勾
- 选中行：底色 `selectionBg`（**不加左侧竖条**，那是"当前对话"专属）
- 元信息和时间：同列表行

---

## 3. 长按 ⋮ 菜单

- **背景列表**：用新的列表行结构（v2 是旧结构）
- **被长按的那条**：整行底色 = **`surfaceContainerLow`**（`--low`）
  - ⚠️ 不要用 `surfaceContainerHigh`（`--high`），太深，看着像禁用
- 底部 sheet 不变

---

## 4. 删除确认

- 背景列表同样换成新结构
- 复选框同多选态

---

## 5. Token 改动（只有两条）

| token | v2 | v3 | 原因 |
|---|---|---|---|
| E 套 `fs-title` | 16 | **15** | 宋体在 16px 下比其他两套宽，标题会比 A/H 先截断 |
| （新增长按态用色） | — | 长按行用 `surfaceContainerLow` | 不用新增 token，复用已有 |

**颜色 token 一条都没动。**
**`row-h` 三套仍然都是 68。**

---

## 6. 没有改的部分

- 聊天页（11 屏）——一条没动
- 设置页（6 屏）——一条没动
- 空态 / 加载中 / 加载失败 / 导入中 / 导入失败——没有行，不用改
- 搜索页——搜索结果本来就是独立结果块，保持 v2 的样子
- 图标、圆角、字重、行高倍数——都没动

---

## 7. 落地顺序建议

1. 先落 **列表行结构**（分组 + 时间右移 + 未读点 + 当前行）
2. 再落 **多选槽位**（复选框放 34 槽位里）
3. 最后落 **长按态底色**（`--low`）

三套皮肤共用一套代码，切皮肤只换 token，**不要为 E 单独写分支**。

---

## 8. 验收要点

- 三套的列表行高必须都是 68（切皮肤列表长度不能跳）
- 标题在 A/E/H 下都要能完整显示（E 因降了 1px 才对齐）
- 长按高亮不能是深灰（要用 `--low`）
- 复选框占位 34，框 20（不能拿 20 直接顶）
